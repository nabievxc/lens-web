# Lens Catalog

A walk-through 3D camera rental shop. Browse hundreds of lenses on the shelves, pick them up, and try them on Sony FX3 and RED Komodo bodies in the back room.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

| Command        | What it does        |
| -------------- | ------------------- |
| `npm run dev`  | Start the next app  |
| `npm run build`| Production build    |
| `npm start`    | Serve the build     |

## Controls

- **WASD** — walk
- **Mouse** — look (click to lock pointer)
- **E / click** — pick up a lens or camera
- **Ctrl / C** — crouch
- **V** — look through a held camera
- **Q / Esc** — put down / exit viewfinder

## Stack

Next.js, React Three Fiber, Three.js, Tailwind CSS.
